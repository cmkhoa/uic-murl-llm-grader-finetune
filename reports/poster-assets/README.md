# MURL poster assets

These visuals are generated deterministically by `scripts/create_poster_assets.py` from versioned repository data.

- [`seven-integration-methods.png`](seven-integration-methods.png) / [`seven-integration-methods.svg`](seven-integration-methods.svg): stacked benchmark composition for the seven core integration-method categories, read from `data/raw/graded-exams.jsonl`. The 47 mixed-review records are disclosed separately in the subtitle.
- [`v08-cross-model-comparison.png`](v08-cross-model-comparison.png) / [`v08-cross-model-comparison.svg`](v08-cross-model-comparison.svg): all 11 audited v0.8 validation arms and five frozen selection measures, read from `reports/v0.8-final/model-summary.csv`.
- [`qwen25-v01-v07-validation-progression.png`](qwen25-v01-v07-validation-progression.png) / [`qwen25-v01-v07-validation-progression.svg`](qwen25-v01-v07-validation-progression.svg): Qwen2.5 v0.1–v0.7 development progression on the common 48-example validation split. Exact plotted values and source reports are recorded in [`qwen25-v01-v07-validation.csv`](qwen25-v01-v07-validation.csv).

The SVG files are editable vector originals for poster layout. The PNG files are high-resolution exports for direct placement.
