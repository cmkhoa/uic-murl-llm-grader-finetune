# MURL v0.8 final handoff

## Research question and frozen protocol

MURL v0.8 asked whether a fixed parameter-efficient grading recipe transfers across small instruction-model families, and which eligible model/recipe pair best balances overall correctness, error taxonomy, and first-error localization.

Selection used only the frozen 48-example validation split. The audit recalculated archived validation outputs, applied precommitted validity, correctness, taxonomy, and localization gates, and ranked eligible arms by the frozen three-metric utility. Training used the training split only; the prompt, model revisions, adapters, chat templates, decoding settings, evaluator, and dataset artifacts were fixed before held-out access. The selected system then produced exactly one greedy output for each of 47 held-out examples, with no retry, repair, or post-test adjustment. Raw outputs were archived before the evaluator was invoked once.

## Final selection and held-out result

The selected system is **Qwen3-4B v0.6 hierarchical multi-task** (`qwen3-4b-murl-v0.8-v0.6`). Its one-time held-out result was:

| Measure | Result |
|---|---:|
| Schema-valid | 47/47 |
| Overall correctness | 39/47 (0.8298) |
| Taxonomy macro-F1 | 0.7037 |
| First-error exact | 24/26 (0.9231) |

The test set contains only 47 examples, and taxonomy supports are sparse: eight of ten non-`none` labels have support five or fewer. These results are a final estimate for the already-selected system, not evidence for another selection round. No post-test tuning, threshold change, prompt change, or model reselection was performed or is permitted from this test result.

## Reproduce from archived outputs only

Run from the repository root with Python 3.10+, NumPy, and Matplotlib. The ignored run archives named in the reports must be present under `runs/baseline/` and `runs/final/`.

```bash
# Reproduce the pre-test cross-family selection audit from archived
# training and validation bundles only.
python3 scripts/v08_reproducibility.py

# Reproduce final-test tables, figures, hashes, and the static render
# from the immutable final-test archives only.
python3 scripts/v08_final_test_artifacts.py
```

These paths do not download or load a model, run generation, read the original held-out split, or perform another held-out evaluation. The selection workflow is intentionally limited to its pre-test validation scope; the final-test workflow verifies the one-generation/one-scoring manifest and reconstructs outputs from the archived result records.

## What is complete / what must not be done next

Complete: cross-family validation audit, frozen winner selection, exactly one held-out generation pass, exactly one scoring invocation, final reporting, figures, manifests, and archive-only reproduction materials.

Do not rerun the held-out test, regenerate model outputs, rescore as a new evaluation, tune on the test result, alter the frozen protocol, or reselect a winner. Any future modeling work must be a separately versioned study with a new untouched test set.
