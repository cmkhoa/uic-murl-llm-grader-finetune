# MURL v0.8 annotation second-review closeout

**Review date:** 2026-11-15  
**Scope:** all 60 source records whose frozen `review_status` is `needs_second_review`  
**Decision:** confirm all 60 label triples without changing the frozen v0.1 dataset

## Method and provenance

Each flagged record was checked against its problem, reference solution, numbered student work, gold feedback, existing review note, and the rules in `docs/annotation-guide.md`. The review independently checked mathematical validity, the earliest-error convention, correctness severity, taxonomy mechanism, valid alternative methods, and the `insufficient_work` policy.

The machine-readable resolution ledger is [`data/processed/v0.1-second-review-ledger.jsonl`](../data/processed/v0.1-second-review-ledger.jsonl). It preserves the original `needs_second_review` status and records a post-study resolution instead of rewriting `data/raw/graded-exams.jsonl`. This is an independent AI-assisted closeout review, not a blinded human adjudication. A faculty or other qualified human should sign off before representing it as human annotation.

The 60 decisions contain 14 `correct`, 14 `minor_error`, 21 `incorrect`, and 11 `insufficient_work` records. All 60 existing correctness, first-error, and taxonomy labels were confirmed. No source edit, split rebuild, training-data rebuild, metric change, or model rerun was performed.

## Policy edge cases retained

- `int_sub_0002` and `int_sub_0025`: the mathematics shown is correct but back-substitution is omitted. The frozen labels treat this as a localized minor substitution error at the last shown step. This is defensible for grading completeness, though a future guide should state the localization rule for omitted final transformations explicitly.
- Eleven `insufficient_work` records: nine state a correct final value without enough method work and two state a wrong value without localizable intermediate work. The labels follow the project rule that step-level grading requires visible evidence, not merely a final answer.
- Correct alternative methods and equivalent forms were retained when every written claim was valid, even when they differ from the reference route.
- A correct final answer does not erase an invalid written intermediate claim; conversely, loose but mathematically coherent notation was not automatically treated as a mathematical error.

## Frozen-study boundary

This closeout resolves the review queue for provenance purposes only. The v0.8 benchmark, hashes, model selection, and one-time test remain exactly as executed. Any future label change must be released as a new dataset version and evaluated with a new untouched test set.
