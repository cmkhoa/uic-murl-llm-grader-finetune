# MURL project write-up

My project, MURL, investigated whether a small open-weight language model could be fine-tuned to assist with grading worked Calc I–II integration solutions. Instead of checking only the final answer, the model received the problem, a reference solution, and a student-style sequence of steps. It learned to return structured JSON containing an overall correctness label, the first incorrect step, an error category, supporting evidence, concise student-facing feedback, and a confidence score. I built a 250-example authored benchmark covering seven core integration methods—substitution, integration by parts, trigonometric integrals, trigonometric substitution, partial fractions, definite integrals, and improper integrals—plus mixed-review problems. Problem families remained separate across the 155-example training, 48-example validation, and 47-example test splits.

I used QLoRA, a parameter-efficient fine-tuning method, to run seven controlled Qwen2.5-3B experiments on a 16 GB Google Colab Tesla T4. Version 0.1 established the initial full QLoRA training baseline; v0.2 added clearer grading-label definitions; and v0.3 added decision rules for selecting the error taxonomy. Version 0.4 balanced every taxonomy category equally during training, which improved diagnosis but reduced grading accuracy, so v0.5 used a moderated balance to recover a better overall tradeoff. Version 0.6 used a hierarchical multi-task objective with extra weight on diagnostic fields, and v0.7 tested two-stage training: ordinary supervision followed by a diagnosis-focused stage. These experiments showed that improving one skill could weaken another, so the project selected models using structured-output validity, grading correctness, taxonomy macro-F1, and first-error localization together. In the final v0.8 cross-family study, I applied the frozen recipe family to Qwen3-4B and Phi-4-mini-instruct while retaining the Qwen2.5 results for comparison.

The selected system was Qwen3-4B with the v0.6 hierarchical multi-task recipe. It produced 47/48 valid outputs and 35/48 correct grades on validation, with 0.6984 taxonomy macro-F1 and exact first-error localization in 19/28 eligible cases. After freezing the model and evaluation settings, one held-out test produced 47/47 valid outputs, 39/47 correct grades, 0.8445 correctness macro-F1, 0.7037 taxonomy macro-F1, and 24/26 exact first-error locations. A qualitative review also found that 43/47 feedback messages scored at least 7/8 for correctness, specificity, actionability, and tone, although four mathematically important failures showed why an instructor should remain in control. If I continued the project, I would start a separately versioned study with a new untouched test set, add real de-identified student work, obtain faculty adjudication, expand rare error categories, and eventually test OCR or handwritten mathematics in a human-in-the-loop grading interface.
